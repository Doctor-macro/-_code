Excel 操作ショートカット｜1枚チートシート

Windows版 Excel / 学習後の「思い出す用」

1. 安全・基本

Ctrl+S
保存
Ctrl+Z
元に戻す
Ctrl+Y
やり直す
Esc
入力・コピーをキャンセル
F2
セルを編集
F4
直前の操作を繰り返す
Ctrl+1
セルの書式設定

2. 移動・選択

Ctrl+↑↓←→
データの端へ移動
Ctrl+Shift+↑↓←→
端まで一気に選択
Shift+↑↓←→
選択範囲を1セルずつ拡張
Shift+Space
行全体を選択
Ctrl+Space
列全体を選択
Ctrl+Home
A1へ戻る
Ctrl+End
最後の使用セルへ
Ctrl+G / F5
指定セルへジャンプ

3. 入力・連続入力

Alt+Enter
セル内改行
Ctrl+Enter
選択範囲へ一括入力
Ctrl+D
上のセルを下へコピー
Ctrl+R
左のセルを右へコピー
Ctrl+E
フラッシュフィル
Ctrl+;
今日の日付を入力
Ctrl+Shift+;
現在時刻を入力
フィルハンドルをダブルクリック
下方向へ自動入力

4. コピー・貼り付け・検索

Ctrl+C
コピー
Ctrl+X
切り取り
Ctrl+V
貼り付け
Ctrl+Alt+V
形式を選択して貼り付け
Ctrl+F
検索
Ctrl+H
置換
コピー → Ctrl+Alt+V
値貼付 / 行列入替 など

5. 行・列・マウス小技

Ctrl++
セル / 行 / 列を挿入
Ctrl+-
セル / 行 / 列を削除
Ctrl+9
選択行を非表示
Ctrl+0*
選択列を非表示
Shift + 境界をドラッグ
間へ差し込んで移動・入替
セル境界をドラッグ
選択範囲を移動
列 / 行境界をダブルクリック
幅 / 高さを自動調整

6. 整理・シート・印刷

Ctrl+Shift+L
フィルター ON / OFF
Alt+↓
ドロップダウンを開く
Ctrl+T
範囲をテーブル化
Ctrl+PgUp/PgDn
前 / 次のシート
Shift+F11
新しいシートを追加
Ctrl + シートタブをドラッグ
シートを複製
F12
名前を付けて保存
Ctrl+P
印刷 / ページ切れ確認
迷ったら Ctrl+Z|長い表は Ctrl+方向キー|貼り付け事故防止は Ctrl+Alt+V|差し込み移動は Shift+ドラッグ
* Ctrl+0 は環境により無効の場合あり
