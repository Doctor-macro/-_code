このガイドの使い方

左の目次から操作を選んで参照できます。印刷・PDF保存にも対応しています。

最初に読む：この資料で扱うこと

本資料は「SharePoint上にあるExcelファイルを、ExcelのPower Queryで取り込む」までを、画面操作の順番に沿って解説します。単一ファイル、同じ形式の複数ファイル、クエリの編集、更新、接続先変更を区別して説明します。

最短ルート（1ファイルの場合）

Teamsの対象チャネル → SharePointサイトを開く → サイトURLを取得 → Excel［データの取得］→［SharePoint フォルダー］→［データの変換］→［Name］・［Folder Path］で絞る → ［Content］のBinary → 対象テーブル → 加工 → ［閉じて読み込む］

重要な考え方

用語 意味
データソース データを取得する元ファイル、サイト、テーブルなど
クエリ 取り込み方法と加工の手順を保存したもの
適用されたステップ 加工履歴。画面右側から修正や削除が可能
更新 保存した処理を再実行し、結果を再取得・再出力すること
補足

Power Queryは基本的に取り込み・整形する機能です。読み込んだ結果を編集しても、その変更が元のSharePoint上のファイルに書き戻されるわけではありません。

1. Teams・SharePoint・OneDriveの違い

ファイルがある場所 保存先の原則 接続前にすること
標準チャネル チームのSharePointサイト チャネルからSharePointを開いてURL確認
プライベート／共有チャネル そのチャネル専用のSharePointサイト 該当チャネルからURL確認
チャットで共有したファイル 送信者のOneDriveなど ファイルの実際の保存先・権限を確認
補足

Teams上で表示されていても、チャットとチャネルは保存先が異なることがあります。共有リンクの画面ではなく、実際の保存先を起点にします。

2. 接続方式を決める

目的 おすすめの接続 留意点
SharePoint上のExcel 1件 SharePoint フォルダー 抽出条件で1ファイルに絞る
月次・部門別の複数Excel SharePoint フォルダー＋ファイルの結合 形式・テーブル名が揃っているか確認
SharePointリストの行 SharePoint Online リスト ファイルとは別物
PCに保存したExcel Excelブック／フォルダー PCの保存先が変わると再設定が必要

3. TeamsからSharePointのサイトURLを取得する

  1. Teamsを開き、対象の「チーム → チャネル」を選択します。
  2. 上部の［共有］を開き、［ライブラリ内］などから取り込みたいExcelファイルの所在を確認します。
  3. ［…］などのメニューから［SharePointで開く］を選びます。UI上の位置はTeamsの更新により異なります。
  4. SharePoint上でサイトのホームを開き、サイトURLを控えます。
  5. 取り込みたいファイル名、フォルダー名、Excel内の「テーブル名／シート名」も記録します。

サイトURLとファイル共有リンクは異なる

用途 例（架空の組織）
サイトURL（接続入力例） https://contoso.sharepoint.com/sites/SalesTeam
ファイルのパス例 https://contoso.sharepoint.com/sites/SalesTeam/Shared%20Documents/General/sales.xlsx
共有リンク例 https://contoso.sharepoint.com/:x:/r/sites/...?...

SharePoint フォルダー接続には基本的に「サイトURL」を入力します。ファイルURLや「リンクをコピー」で得た共有URLをそのまま貼り付けると、接続に失敗することがあります。

補足

実際のライブラリ名、言語による表示名、フォルダーパスは組織環境により異なります。

4. ExcelからSharePointフォルダーへ接続する

  1. Excelデスクトップアプリで新しいブックまたは集計用ブックを開きます。
  2. ［データ］→［データの取得］から［SharePoint フォルダー］を選びます。メニュー分類が異なる場合はコネクタ名を探します。
  3. ［サイトURL］欄へ「3」で控えたサイトURLを入力し、［OK］を選びます。
  4. 初回接続なら［組織アカウント］を選び、閲覧権限のある会社・学校アカウントでサインインします。
  5. ファイル一覧が表示されたら、まず［データの変換］を選びます。

接続直後の一覧に「対象サイト内の別チャネルやフォルダーのExcelファイル」も含まれる場合があります。すぐに全件結合せず、Power Queryエディターで抽出条件を設定します。

5. 対象ファイルを1件だけ指定する

  1. Power Queryエディターの一覧から［Name］列を確認します。
  2. ［Name］列の▼で取り込みたいExcelファイル名だけに絞り込みます（例：sales_2026.xlsx）。
  3. 同じ名前のファイルが複数存在する場合は［Folder Path］でも保存先を絞ります。
  4. 1行だけ残ったことを確認し、［Content］列の［Binary］をクリックします。
  5. Excelブックのオブジェクト（テーブル／シート）が表示されたら、目的のものを選びます。
  6. プレビューで列名と数件の値を確認し、加工へ進みます。
列名 用途
Name ファイル名を特定する
Folder Path 同名ファイルを取り違えない
Extension 拡張子の絞り込みに使う
Content 実ファイル本体。Binaryをクリックすると開ける
補足

名前だけではなく「フォルダー＋ファイル名」で特定すると、意図しないファイルを取り込む事故を減らせます。

6. Excelブック内のテーブル・シートを選ぶ

Power QueryはExcelファイルの中から、テーブル・シート・名前付き範囲などを取得できます。元ファイル側でデータ範囲をExcelテーブルとして定義すると、新しい行が追加されても範囲を管理しやすくなります。

選択項目 利点 注意
テーブル（Table） 範囲や列名を管理しやすい 名前変更すると接続手順に影響
シート（Sheet） 既存の未整備ファイルも取得しやすい 空白行や余計な見出し行に注意
名前付き範囲 特定のセル範囲だけ対象 参照範囲が保守されているか確認

7. 複数のExcelファイルをまとめる場合

  1. SharePoint フォルダー接続後の一覧で、まず対象フォルダー、拡張子、ファイル名規則を絞ります。
  2. Excelの編集中に作られる「~$」で始まる一時ファイルや、関係ない帳票を除外します。
  3. 対象ファイルのみ表示された状態で［Content］列の「ファイルの結合」を実行します。
  4. サンプルファイルの中から、全ファイルで共通のテーブル名／シート名を選びます。
  5. 結合後の件数・列名・エラー数を確認してから読み込みます。

同じフォルダーの複数ファイルを一括結合する機能は、各ファイルが同じ表構造であることを前提に動作します。Excelの表名や列名が異なる場合は別途調整が必要です。

8. Power Queryエディターの見方

場所 名称 役割
左 クエリ一覧 別の加工処理を選ぶ
中央 プレビュー 現在のステップでのデータを確認
右 クエリの設定／適用されたステップ 加工履歴の確認・修正

変換を行うたびにステップが追加されます。右のステップをクリックすると途中の結果を確認できます。歯車があるステップは設定画面から直せることが多く、不要なステップは削除できます。

9. 基本の加工例

やりたいこと 代表的な操作 注意点
不要な列を消す 対象列を選択 → 列の削除 後段で参照する列を削除しない
必要な行だけ残す 列の▼ → フィルター 更新で新行にも同じ条件が適用される
日付を日付にする 列を選択 → データ型 → 日付 異常値がエラーにならないか確認
表記ゆれをそろえる 値の置換 null と0の違いを把握
文字列を分割 列の分割 区切り記号や分割数を確認
重複を除く 列選択 → 重複の削除 どの列の組合せを重複とするか決める
補足

プレビューの内容だけでなく、読み込み後の「件数・数量合計・最新日付」を検証してください。

10. 「追加」と「マージ」の違い

クエリの追加（Append）は、同じ列構造を持つ表を縦方向に連結します。例：9月の売上と10月の売上。クエリのマージ（Merge）は、店舗コードなどのキーをもとに、別表の情報を横方向に結合します。例：売上データに店舗マスタから店舗名を付与。

機能 結果 業務例
追加 行を増やす 売上_9月＋売上_10月
マージ 列を増やす 売上表＋店舗マスタの店舗名

11. 加工結果をExcelに読み込む

  1. Power Queryエディターで［ホーム］→［閉じて読み込む］を選びます。
  2. 必要なら［閉じて読み込む先］で、テーブル／接続のみ／データモデルなどを指定します。
  3. Excelシートに一覧表が表示されたら、件数や数値の合計を確認します。
  4. 集計用の数式やピボットは、読み込み先のテーブルを参照するように設計します。

読み込まれたテーブルを直接編集した場合、次回の更新で書き換わる可能性があります。手入力は別シートに分けるか、Power Queryの変換に組み込むのが基本です。

12. 元データが変わった場合：更新する

  1. 元ファイルがSharePoint上で保存済みになっていることを確認します。
  2. 集計ブックを開き、Excel［データ］→［すべて更新］を選びます。
  3. エラーがないことを確認し、結果の件数・日付範囲・金額を見直します。
  4. 必要に応じて接続のプロパティで、起動時や一定間隔の更新設定を確認します。

更新は「取り込みから加工・出力までの処理をもう一度実行する」ものです。常時同期を意味しません。元ファイルの列名やテーブル名を変更すると、更新エラーの原因になる場合があります。

13. 加工内容を変更する

  1. Excelで［データ］→［クエリと接続］を開きます。
  2. 変更対象のクエリを右クリックして［編集］を選びます。
  3. 右側の［適用されたステップ］を上から順に確認し、変更したいステップを選びます。
  4. 歯車が表示される場合は設定を編集します。不要なステップは削除可能です。
  5. 後続のステップでエラーが発生していないか確認し、［閉じて読み込む］を実行します。
補足

ステップの途中を変更すると、その後に続く列名参照・型変換・マージなどに影響する場合があります。

14. 接続先が変わった場合：どこを直す？

発生した変更 修正箇所の目安 再確認
データが増えた／値だけ変更 ［すべて更新］ 件数・合計
ファイル名の変更 Nameフィルター 対象が1件か
同じサイト内でフォルダー移動 Folder Pathフィルター パスの一致
別のSharePointサイトに移動 ［ソース］URLまたはデータソース設定 権限・抽出条件
テーブル／シート名の変更 ナビゲーションの指定 表構造
組織アカウントの変更 データソース設定・アクセス許可 サインイン

接続先変更の基本手順

  1. Excelの［クエリと接続］から対象のクエリを［編集］します。
  2. 右側の［ソース］ステップを選び、歯車があればURLを変更します。
  3. ［フィルターされた行］などの条件で［Name］と［Folder Path］を更新します。
  4. 必要に応じて［ナビゲーション］手順の表名／シート名を修正します。
  5. ［閉じて読み込む］後、結果件数などを確認します。

15. 認証・アクセス許可を直す

  1. Excel［データ］→［データの取得］→［データソース設定］を開きます。
  2. 「現在のブックのデータソース」から対象SharePointサイトを確認します。
  3. 必要に応じて［アクセス許可の編集］や［アクセス許可のクリア］で認証情報を再設定します。
  4. 組織アカウントを選び直し、実際に権限があるアカウントでサインインします。
  5. SharePointのWeb画面で元ファイルの閲覧ができることも確認します。
補足

Power Query側の認証情報を消しても、SharePointサイトそのものにアクセス権が付与されるわけではありません。権限不足なら管理者・ファイル所有者への依頼が必要です。

16. エラー別トラブルシューティング

エラー・現象 先に疑うこと 対応例
資格情報／アクセス拒否 URL・アカウント・権限 サイトURLとログインを再確認
ファイルが0件 Name / Folder Pathの抽出条件 ファイル移動・改名を確認
Keyが一致しない 表名／シート名の変更 ナビゲーションを見直す
指定した列がない 列見出し変更・欠損 列名・変換順を見直す
不要なファイルも結合 フォルダー・拡張子の条件 結合前に除外
更新が遅い 大量ファイルを取得 先にファイル・列を絞る

17. 継続運用のための設計ルール

  • 元データの列名・テーブル名・型をできるだけ固定する。
  • ファイル名規則と対象フォルダーを運用ルールにする。
  • サイトURLとファイル抽出条件（Name／Folder Path）を記録する。
  • 集計ブックを別担当者へ渡す際は、参照権限と更新手順も渡す。
  • 変更後には、件数／合計／日付範囲／エラー件数を必ず照合する。

18. 練習課題（最短10分）

  1. SharePointのテスト用フォルダーに「sales.xlsx」を置き、「Sales」というExcelテーブルを含めます。
  2. SharePoint フォルダーから接続し、NameとFolder Pathで1件に絞ります。
  3. ContentのBinaryを開き、Salesテーブルを取得します。
  4. 不要列を1つ削除し、日付列の型を設定します。
  5. Excelへ読み込み、元ファイルに行を1件追加し、［すべて更新］します。
  6. 件数が1増えたことを確認し、Nameフィルターの変更も試します。

付録A　画面が異なる場合の考え方

Microsoft 365のUIは順次更新されます。この資料の「ボタン名」は利用環境で完全一致しないことがあります。メニューが見つからない場合は、操作名「SharePoint フォルダー」「データソース設定」「クエリと接続」「閉じて読み込む」を検索してください。

Excel for the web / Mac では接続・編集機能や対応コネクタがWindowsデスクトップ版と異なる場合があります。本書はWindowsデスクトップ版を前提にしています。
